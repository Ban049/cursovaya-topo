# 📘 Руководство пользователя (Enterprise Console System)

Приложение представляет собой интерактивную консоль (REPL) для управления заметками, пользователями и мониторингом системы.

## 🔑 Авторизация
*   `login -u [username] -p [password]` — Вход в систему.
*   `logout` — Выход из текущей сессии.

## 📝 Заметки (Только для роли User)
*   `note list` — Просмотр списка своих заметок.
*   `note add -t "Заголовок" -c "Содержимое"` — Создание новой заметки.
*   `note edit -id [ID] -t "Новый заголовок" -c "Новый текст"` — Редактирование существующей заметки.
*   `note del -id [ID]` — Удаление заметки.

## 🛡️ Управление пользователями (Только для роли Admin)
*   `user list` — Список всех пользователей системы.
*   `user add -u [имя] -p [пароль] -r [Роль]` — Создание пользователя.
    *   Доступные роли: `User`, `Admin`, `WatchdogAdmin`.
*   `user del -id [ID]` — Удаление пользователя по ID.

## 📡 Watchdog (Только для роли WatchdogAdmin)
*   `watchdog run` — Запуск фонового сбора метрик CPU.
*   `watchdog stop` — Остановка сбора метрик.
*   `watchdog config -i [секунды]` — Установка интервала сбора данных (например, `-i 10`).
*   `watchdog status` — Проверка состояния модуля.

## ⚙️ Системные команды (Только для Admin)
*   `system logs -n [кол-во]` — Просмотр последних записей системного журнала.
*   `system update` — Подготовка системы к обновлению (применится при перезапуске).

## 🆘 Общие команды
*   `help` — Вывод справки по доступным командам.
*   `exit` — Завершение работы приложения.
